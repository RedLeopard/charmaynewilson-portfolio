# Charmayne Wilson | Portfolio Website

A professional portfolio website built for Charmayne Wilson, a Data & Business Analytics Specialist.

Developed and deployed by Edward Thornton.

**Live website:** https://charmaynewilson.click

## Technology Stack

- **Frontend:** HTML and CSS
- **Hosting:** AWS Amplify Hosting
- **Domain Registration and DNS:** Amazon Route 53
- **Version Control:** GitHub
- **CI/CD:** Automatic deployments through AWS Amplify

## Architecture

The domain is registered and managed through Amazon Route 53. AWS Amplify hosts the website and connects to this GitHub repository to automatically deploy updates pushed to the `main` branch.

The site uses plain HTML and CSS with no build step required.

## Local Development

Clone the repository and open `index.html` in your browser to preview the website.

## Deployment

1. Edit the website files.
2. Preview and verify the changes locally.
3. Commit and push to `main`.
4. AWS Amplify automatically deploys the updated site.

## Project Purpose

Create a professional online presence for Charmayne while demonstrating static website development, AWS hosting, domain configuration, and automated deployment.
